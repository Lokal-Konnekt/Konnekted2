# Bundled MilkDrop renderer

These files are bundled so MilkDrop visualizations work on first launch without reaching a CDN.

- `butterchurn.min.js`: Butterchurn 2.6.7, the WebGL MilkDrop renderer.
- `butterchurnPresetsMinimal.min.js`: butterchurn-presets 2.4.7 minimal preset pack.

Upstream projects:
- https://github.com/jberg/butterchurn
- https://github.com/jberg/butterchurn-presets
